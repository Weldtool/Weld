# Archived manuscript (superseded)

`main.tex` + `sections/` + `refs.bib` are an earlier draft of the TOSEM
submission, titled *"Context-Scoped AI Agents in Integrated Developer
Workspaces: A Between-Subjects Study of Information Breadth and Task
Performance."*

It is superseded by `../WELD_TOSEM_PAPER.tex` and is kept only for reference.

Two reasons it was retired:

1. **Framing.** It names the independent variable *information breadth* /
   *context breadth*. That wording implies capability was held fixed while
   visibility varied, which is not what the apparatus does — the agent's tools
   widen with its scope. `WELD_AGENT_STUDY_DESIGN.md` records the decision to
   call the variable **agent scope** instead, and a reviewer would have caught
   the mismatch.
2. **Currency.** Last substantive edit 2026-06-22; the live paper carries the
   current design, measures, analysis plan, and sensitivity analysis.

`refs.bib` belongs to this draft. The live paper's bibliography is
`../weld-tosem.bib` — do not confuse the two; they share only one key
(`mark2008cost`).

Nothing here should be edited. If something in it is worth keeping, move it into
the live paper rather than reviving this one.
